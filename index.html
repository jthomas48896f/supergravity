Claim

The Sun is 99.86 percent of all the mass in the solar system.

In plain words: The Sun holds 99.86 percent of the solar system's mass. Everything else, every planet, moon, and rock, is the remaining 0.14 percent.

In simpler words: Almost everything in the solar system is the Sun. If you could weigh it all, the Sun would be 99.86 parts out of 100. All the planets together are just a tiny piece.

Ground

This claim stands in the Atlas topic Solar System, in the file content/astronomy.js in this repository. That file records these sources for the topic:

  • Wikipedia: Solar System
  • NASA: Solar System
  • NASA Astronomy Picture of the Day

The first source states the figure directly: "The Sun accounts for 99.86% of the Solar System's total mass."

For agents and builders

The tutor that used to headline Atlas was dropped on October 15, 2026, by direction. Its eval harness stays in this repository as an archived experiment, in the folder tools/tutor-eval. The harness grades answers drawn from the atlas content for groundedness (whether the facts the atlas states appear in the answer) and citation presence, over 12 questions drawn from the atlas itself.

Committed baseline results, from the run recorded in the file tools/tutor-eval/results/baseline-report.md: groundedness 0.833, citation rate 1, correct source rate 0.75, across the 12 questions. The gates are groundedness 0.75, citation rate 1, and correct source rate 0.75. Run it with npm run eval:tutor. The build smoke test is npm test and the lint is npm run lint, as defined in package.json.

The Solar System topic file named in the Proof is content/astronomy.js in this repository. The full app sits behind the proof screen at atlas.html in this repository.

For agents: the machine files are data.js and the topic files under content/, each topic with its recorded sources and its verified date. The Proof seal stands in full in the Seal block above, so it can be recomputed from the four printed lines.
